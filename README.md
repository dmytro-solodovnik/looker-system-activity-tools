# DV Users Analytics

This repo contains programmatic models/dashboards which are tightly integrated with Looker. Looker uses this data to represent data using it's own DSL.

## Environments
This project is presented on 3 Looker Instances:

Stg:  https://doubleverifystg.cloud.looker.com/ - dev/tests

Prod: https://doubleverify.cloud.looker.com/ - internal user statistic

Prod Ext:  https://doubleverifyext.cloud.looker.com/ - external user statistic

## Code Deployment
Code Deplyment is managed by Looker and is stored in the repository and are version control by default.
There is no automatic pipeline on Gitlab.
